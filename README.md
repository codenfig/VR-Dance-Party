# VR Dance Party — Android Phone + VR Box — Sprint 1

A Unity/C# prototype of an immersive dance club for an Android phone inside a basic VR Box viewer.

## Features
- One-click Unity Editor scene generator with a procedural stage, dance floor, and colored club lights.
- A placeholder 3D dancer whose movement follows a 120 BPM rhythmic demonstration.
- Original, synthesized metronome audio; no commercial music or copyrighted recordings are bundled.
- Side-by-side stereoscopic cameras with basic 3DoF gyroscope viewing on supported Android phones.
- Testing controls for pause/resume, restart, dance style, recenter, and stereo/mono.

**Development status:** Source-code starter, **not** a complete Unity project or an APK. This prototype has not yet been compiled, hardware-tested, or performance validated. The 50 ms beat alignment requirement is not yet measured. It does not include lens distortion correction, calibrated headset optics, tracked hand controllers, multiplayer, music file import, automatic beat detection, recording, or a production VR SDK.

## Setup
1. Install Unity Hub and a compatible Unity editor (Unity 2022.3 LTS or Unity 6) with **Android Build Support**, **Android SDK & NDK Tools**, and **OpenJDK**.
2. Create a Unity **3D (Built-In Render Pipeline)** project.
3. Copy the `Assets/Scripts` and `Assets/Editor` folders from this repository into your Unity project's `Assets` folder, or clone the repository and use its Assets folder in a new project.
4. Let Unity compile. Select **VR Dance Party > Create First Playable Scene** from the Unity menu.
5. Open `Assets/Scenes/VRDanceParty_FirstScene.unity` if necessary, then press **Play** to test in the editor. Arrow keys can simulate horizontal head movement on a desktop.
6. Go to **File > Build Settings** (or **Build Profiles** in newer Unity), switch to Android, enable the generated scene, set a package identifier (e.g. `com.student.vrdanceparty`) and landscape orientation.
7. In **Project Settings > Player > Other Settings > Active Input Handling**, select **Both** or **Input Manager (Old)** for this prototype's legacy `Input` APIs.
8. Enable USB debugging on your Android phone, connect it, then choose **Build And Run**.
9. Verify split-screen rendering and gyroscope motion on the phone **before** placing it in the VR Box viewer.

## Interaction and safety
The test buttons are displayed on the phone screen and cannot readily be touched inside the VR Box. Start the experience before inserting the phone. Gaze-selection or an external Bluetooth controller is a planned future improvement.

Use the prototype while seated and stationary, with a clear surrounding area. Stop immediately if dizziness, nausea, or visual discomfort occurs. Phone gyroscope orientation conventions differ, so `ReadGyro()` in `Assets/Scripts/VRBoxDemo.cs` may need tuning for the actual device. The basic stereo display may not fit every viewer's lenses or IPD.

## Sprint 2 — Gaze controls
The scene generator now adds a hands-free gaze menu. While wearing the viewer, look at one of the four virtual buttons for about **1.6 seconds** to activate **Pause/Play**, **Restart**, **Dance Style**, or **Recenter**. The small white reticle marks the forward gaze direction. The original touch buttons remain available for phone-out-of-viewer testing.

**Update existing Unity projects:** After pulling the latest repository changes, run **VR Dance Party > Create First Playable Scene** again to regenerate the scene with the gaze menu. This replaces the generated scene, so save any custom edits elsewhere first.

**Known limitations:** The gaze menu is an initial implementation and has not been verified on physical Android hardware. Some viewer/phone combinations may need camera field-of-view, eye separation, or gyroscope orientation calibration. Do not use this prototype while walking or driving.
